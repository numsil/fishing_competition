1. 피드 화면 (A-3-1)
==============================================================================

★★★ □ 앱 켜기 → 메인 피드 진입 → 게시물 20개 표시
★★★ □ 끝까지 스크롤 → 추가 게시물 자동 로드 (하단 로딩 spinner)
★★★ □ 마지막 도달 시 spinner 사라짐, 더 이상 호출 안 됨
★★★ □ Pull-to-refresh (위로 당기기) → 첫 페이지부터 다시 로드
★★  □ 게시물 작성 → 피드 상단 표시 (업로드 후 invalidate)
★★  □ 게시물 댓글 추가 → 댓글 수 갱신
★★  □ 게시물 삭제 → 피드에서 사라짐
★   □ 검색창 활성 → 키워드 입력 → 현재 로드된 페이지에서 필터링
★   □ 검색 모드 종료 → 페이지네이션 복귀

==============================================================================
2. 리그 점수 랭킹 (A-3-2)
==============================================================================

★★★ □ 랭킹 탭 → 리그 탭 진입 → 결과 표시
★★★ □ 결과: 운영자 13274 / 루코 426 / 장이수팀장 110
       (Supabase RPC 결과와 동일해야 함)
★★  □ Pull-to-refresh → 정상 갱신
★★  □ 시즌 표기 "2026 시즌" 바뀌지 않음 (단순 표시 유지)

⚠️ 주의: 작년에 점수 많았던 사용자가 줄어든 것은 정상 (시즌 필터 적용)

==============================================================================
3. 개인 점수 랭킹 (A-3-3)
==============================================================================

★★★ □ 랭킹 탭 → 개인 탭 진입 → 결과 표시
★★★ □ 결과: 운영자 23766 / 빌런 708 / 바르칸 458 / 장이수팀장 442 / 입질가즘 110
       (Supabase RPC 결과와 동일해야 함)
★★  □ Pull-to-refresh → 정상

==============================================================================
4. 프로필 우승/참가 통계 (A-3-4)
==============================================================================

★★★ □ 본인 프로필 진입 → "리그참가" / "우승" 박스 표시
★★★ □ 운영자 프로필: 0 / 0 (in_progress 리그만 참가 중)
★★  □ 다른 유저 프로필 진입 (예: 장이수팀장) → 통계 표시
★★  □ completed 리그가 있는 사용자 → 카운트 정상

⚠️ 이전과 결과가 달라질 수 있는 케이스:
- 미승인 게시물로 우승 판정됐던 사용자 → 카운트 줄어듦 (정합성 개선)

==============================================================================
5. 리그 상세 화면 (A-3-7, A-3-8)
==============================================================================

★★★ □ 리그 목록 → 리그 카드 진입 → 모든 정보 정상 표시
       - 제목, 짧은 설명
       - 시작/종료 시간, 입장료, 최대 참가자 수
       - 룰, catch_limit, 상금 정보
       - 호스트 이름/아바타
       - 소개 이미지 (있으면)
       - 공개/갤러리 허용 여부
★★★ □ "참가자 N명" 숫자 정상 (0 아님)
★★  □ 리그 수정 화면 (호스트만): 진입 → 기존 값 모두 입력란에 채워짐
       - 특히 "짧은 설명(short_description)" 잘 표시되는지

==============================================================================
6. 리그 목록 / 마이리그 (A-3-8)
==============================================================================

★★★ □ 리그 메인 (탭 하단 메뉴) → 카드 목록 → 각 카드의 "참가자 N명" 정상
★★★ □ 마이리그 (탭 하단) → 호스트한 탭 → 카드 "N명" 정상
★★★ □ 마이리그 → 참가한 탭 → 카드 "N명" 정상
★★  □ 참가 신청/취소 후 카운트 갱신 (다른 화면 갔다 와도 OK)

==============================================================================
7. 리그 참가자 상세 (A-3-11, A-3-7)
==============================================================================

★★★ □ 리그 상세 → 랭킹 탭 → 참가자 클릭 → 참가자 상세 진입
★★★ □ 게시물 카드 정상 표시 (이미지/길이/위치 등)
★★  □ 카드 클릭 → 게시물 상세 화면 정상 진입
       (Post 객체 모든 필드 정상)

==============================================================================
8. 프로필 — 최대어 카드 (A-3-16)
==============================================================================

★★★ □ 본인 프로필 → 최대어 카드 표시
       - 어종 (fish_type)
       - 길이 (length)
       - 장소 (location)
       - 날짜 (created_at)
★★  □ 다른 유저 프로필도 동일 표시

==============================================================================
9. 캐시 효과 (D-1-1) — keepAlive
==============================================================================

★★  □ 프로필 진입 → 다른 화면(피드 등) → 빠르게 다시 프로필
       → 깜빡임 없이 즉시 표시 (재페치 안 함)
★★  □ 마이리그 ↔ 다른 탭 왕복 → 즉시 표시
★★  □ 랭킹 ↔ 다른 탭 왕복 → 즉시 표시
★   □ 인증 화면 진입 후 빠른 재진입 → 즉시 표시

⚠️ 이번 작업으로 수동 새로고침 (pull-to-refresh) 외에는
   N분간 같은 데이터 표시. 정상.

==============================================================================
10. 자동 새로고침 축소 (F-1) — _refreshAll
==============================================================================

★★  □ 리그 상세 진입 → 다른 앱 (메시지 등) 잠깐 → 다시 돌아옴
       → 랭킹 탭 자동 새로고침 일어나지 않음 (5분 캐시 유지)
★★  □ 호스트라면: 심사 탭은 그대로 새로고침 됨
★★  □ 사용자가 직접 액션 (참가/승인) 후엔 정상 갱신

==============================================================================
11. 토큰 갱신 차단 (E-5/H-2) — authState select
==============================================================================

★   □ 앱 1시간+ 켜둠 → 프로필/마이리그 자동 재페치 일어나지 않음
       (체감으론 확인 어려움. Supabase 대시보드 호출 수로 검증)
★★  □ 로그아웃 → 로그인 흐름: 정상 동작 (재로그인 후 데이터 정상)

==============================================================================
12. 기타 일반 회귀
==============================================================================

★★  □ 게시물 업로드 (이미지/동영상)
★★  □ 댓글 작성 / 삭제
★★  □ 리그 생성 / 수정 (호스트)
★★  □ 리그 참가 / 취소
★★  □ 리그 진행 (호스트가 status 변경)
★★  □ 호스트의 조과 심사 (승인/거부)
★★  □ 인증 화면 (검증자 권한)
★★  □ 운영자 화면 (어드민)
★★  □ 프로필 수정
★★  □ 다른 유저 프로필 진입
★★  □ DM 화면 (DM은 이번 작업에서 제외 — 별 변화 없어야 함)
