------------------------------------------------------------------------------
대상: lib/core/utils/image_url.dart (신규 — 사용자 사전 동의 필요)

작업 흐름:
  - Supabase Storage public URL은
      https://{project}.supabase.co/storage/v1/object/public/{bucket}/{path}
    형태. Image transformation은
      https://{project}.supabase.co/storage/v1/render/image/public/{bucket}/{path}?width=...&quality=...
    경로로 호출.
  - 헬퍼 함수: 원본 URL → render URL 변환 + width/quality 파라미터 부착
  - 빈 URL/이미 render인 URL/외부 URL은 원본 반환 (안전)
  - 디바이스 픽셀 비율 옵션도 고려 (선택, 단순화 위해 width 인자 1개로 시작)

신규 파일이라 사용자 사전 동의 필요. CLAUDE.md "새 통합 위젯 추가 시 사용자에게
먼저 확인" 규칙 준수.

검증:
  □ 단위 테스트 또는 디버그 출력으로 변환 결과 확인
  □ 외부 URL(https://example.com/...) 통과 확인

δ1-1. SQL 함수 작성
------------------------------------------------------------------------------
도구: Supabase Studio → SQL Editor

작성 함수 (개념만):
  - get_league_score_ranking(top_n int default 10, season_year int default null)
    반환 셋: user_id uuid, username text, avatar_url text, total_score int
    내부:
      WITH catch_scores AS (
        SELECT user_id, COALESCE(SUM(score), 0) AS s FROM posts
        WHERE league_id IS NOT NULL AND review_status='approved'
              AND COALESCE(is_deleted, false) = false
              AND (season_year IS NULL OR
                   created_at >= ... AND created_at < ...)
        GROUP BY user_id
      ),
      bonus_scores AS (
        SELECT user_id, COALESCE(SUM(rank_bonus), 0) AS s
        FROM league_participants
        WHERE rank_bonus > 0 AND ... 시즌 필터 ...
        GROUP BY user_id
      )
      SELECT u.id, u.username, u.avatar_url,
             COALESCE(c.s, 0) + COALESCE(b.s, 0) AS total
      FROM users u
      LEFT JOIN catch_scores c ON c.user_id = u.id
      LEFT JOIN bonus_scores b ON b.user_id = u.id
      WHERE COALESCE(c.s, 0) + COALESCE(b.s, 0) > 0
      ORDER BY total DESC
      LIMIT top_n;

δ3-1. get_user_profile_summary SQL
------------------------------------------------------------------------------
도구: Supabase Studio
함수: get_user_profile_summary(p_user_id uuid)
  반환 (1행):
    id, email, username, user_key, avatar_url,
    manner_temperature, is_lunker_club,
    league_score, angler_score,
    participation_count, win_count,
    max_fish_id, max_fish_image_url, max_fish_length,
    max_fish_fish_type, max_fish_location, max_fish_created_at
  내부:
    - users에서 프로필 정보
    - posts SUM(score) 시즌 필터 — league 게시물 (league_score)
    - posts SUM(score) — 개인기록 (angler_score)
    - league_participants 참가했던 모든 리그 → status='completed' 필터
    - 각 완료 리그에서 본인 우승 여부 판정 (룰 분기 SQL)
      — 가장 까다로운 부분
    - posts 최대어 1행

  우승 판정 SQL (개념):
    WITH user_leagues AS (
      SELECT lp.league_id, l.rule, l.catch_limit
      FROM league_participants lp
      JOIN leagues l ON l.id = lp.league_id
      WHERE lp.user_id = p_user_id AND l.status = 'completed'
    ),
    league_user_scores AS (
      -- 각 리그의 모든 사용자 점수 계산
      SELECT ul.league_id, p.user_id,
             CASE WHEN ul.rule = '마릿수' THEN COUNT(*)
                  ELSE -- top catch_limit 합산
             END AS user_score
      FROM user_leagues ul
      JOIN posts p ON p.league_id = ul.league_id
            AND p.review_status = 'approved'
            AND COALESCE(p.is_deleted, false) = false
      GROUP BY ul.league_id, p.user_id, ul.rule
    ),
    league_winners AS (
      SELECT league_id, user_id,
             RANK() OVER (PARTITION BY league_id ORDER BY user_score DESC) AS rk
      FROM league_user_scores
    )
    SELECT COUNT(*) FILTER (WHERE rk = 1 AND user_id = p_user_id) AS win_count,
           COUNT(DISTINCT league_id) AS participation_count
    FROM league_winners;

  ※ "마릿수" 외 룰의 top catch_limit 합산은 lateral join + DENSE_RANK + LIMIT
    또는 CTE 분해. 실제 작성 시 클라 기존 로직과 결과 비교 필수.
