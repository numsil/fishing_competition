# 신규 빌드 테스트 체크리스트 (1.0.1+55)

작성일: 2026-10-09

이번 빌드에 들어간 변경과, 그 변경이 건드린 **기존 흐름까지** 포함한 목록이다.
`[ ]` 를 채우며 진행하고, 실패한 항목은 번호와 증상을 적어두면 바로 고칠 수 있다.

---

## A. 조과 등록 — 가장 중요

`createPost` 에 사진 해시 계산이 끼어들었다. **여기가 깨지면 조과 등록 자체가 막힌다.**

- [ ] **A1. 개인 조과 1장 등록** (카메라 촬영 → 길이 입력 → 등록)
  - 정상 등록되고 "조과가 기록되었습니다 🎣" 가 뜬다
- [ ] **A2. 개인 조과 1장 등록** (앨범에서 1장만 선택)
  - 기존 단일 화면으로 넘어간다 (일괄 화면 아님)
- [ ] **A3. 리그 조과 등록**
  - 리그 상세 → 조과 등록 → 정상 등록
- [ ] **A4. 일반 피드 글 등록** (사진 여러 장 / 동영상)
  - 기존대로 등록된다 (중복 차단 대상 아님)

---

## B. 같은 사진 중복 차단 (신규)

- [ ] **B1. 같은 사진으로 개인 조과 2회 등록**
  - 두 번째에서 **주황 배너**: "이미 등록된 사진입니다. 다른 사진으로 인증해주세요."
- [ ] **B2. 같은 사진을 한 리그에 2회 등록** → 차단된다
- [ ] **B3. 같은 사진을 리그 1회 + 개인기록 1회** → **둘 다 등록된다** (정상 흐름)
- [ ] **B4. 개인기록 삭제 후 같은 사진 재등록** → 등록된다
- [ ] **B5. 차단된 뒤 다른 사진으로 재시도** → 정상 등록된다

> 참고: 차단은 업로드 **전**에 걸리므로 즉시 뜬다. 오래 기다렸다 실패하면 이상한 것.

---

## C. 앨범 여러 장 일괄 등록 (신규)

- [ ] **C1. 앨범에서 3~4장 선택** → 일괄 등록 화면이 뜨고 썸네일이 모두 보인다
- [ ] **C2. 사진마다 길이 입력** → 버튼이 "N건 등록하기" 로 실시간 변한다
- [ ] **C3. 일부만 길이 입력 후 등록** → 입력한 것만 등록된다
- [ ] **C4. ✕ 로 사진 제외** → 목록에서 빠지고 카운트가 줄어든다
- [ ] **C5. 전부 제외** → 화면이 자동으로 닫힌다
- [ ] **C6. 위치·메모 입력 후 등록** → 등록된 모든 조과에 같은 값이 들어간다
- [ ] **C7. 등록 중 진행률** → "등록 중 2/5" 처럼 표시된다
- [ ] **C8. 이미 등록한 사진을 섞어서 등록**
  - 나머지는 등록되고 요약에 "N건은 이미 등록된 사진" 이 표시된다
- [ ] **C9. 10장 초과 선택 시도** → 10장으로 잘리고 안내가 뜬다
- [ ] **C10. 등록 후 개인 기록 목록** → 등록한 건수만큼 바로 보인다

## D. 피드 정렬 (신규)

- [ ] **D1. 피드 진입** → 예전보다 **최근 글이 위쪽**에 보인다
- [ ] **D2. 당겨서 새로고침** → **순서가 바뀐다**
- [ ] **D3. 새로고침 여러 번** → 매번 다른 순서
- [ ] **D4. 아래로 스크롤해서 다음 페이지 로딩**
  - **같은 글이 두 번 나오지 않는다** ← 중요
  - 중간이 비어 보이지 않는다
- [ ] **D5. 스크롤 중 글이 갑자기 재배치되지 않는다**
- [ ] **D6. 피드 → 다른 탭 → 피드 복귀** → 순서가 유지된다 (5분 캐시)

## E. 리그 심사 — 수치 수정 (신규)

리그 **개설자 계정**으로, **진행 중(in_progress)** 리그에서만 심사 탭이 보인다.

- [ ] **E1. 심사 탭 → 조과 상세** → 수치 옆에 **수정** 버튼이 보인다
- [ ] **E2. 수정 버튼** → 다이얼로그에 현재 값이 채워져 있다
- [ ] **E3. 길이 변경 후 저장** → "수정되었습니다", 화면 값이 바뀐다
- [ ] **E4. 수정된 조과** → "원래 45.0cm (수정됨)" 이 표시된다
- [ ] **E5. 리그 순위** → 수정 즉시 반영된다
- [ ] **E6. 작성자 계정** → 푸시 알림 "리그 조과 길이가 ○○ → ○○ 로 수정되었습니다"
- [ ] **E7. 알림 목록** → "○○님이 조과 기록을 수정했습니다", 탭하면 해당 글로 이동
- [ ] **E8. 무게 규칙 리그** → 단위가 g 으로 나온다
- [ ] **E9. 기존 보류/보류 해지** → 그대로 동작한다

## F. 조과 인증 심사

- [ ] **F1. 심사위원 계정으로 승인 1표** → 에러 없이 처리된다
- [ ] **F2. 다른 심사위원이 승인 2표째** → 목록에서 사라지고 점수가 반영된다
- [ ] **F3. 거절 1표** → 즉시 거절 처리된다
- [ ] **F4. 어드민 계정** → 전체 대기 목록이 보이고 즉시 승인/거부가 된다

> 서버에서 이미 검증된 로직이다. 앱에서는 **에러 없이 처리되는지**만 보면 된다.
> 조용히 실패하던 기존 버그는 이제 에러 배너로 드러난다.
