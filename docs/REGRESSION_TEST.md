# 회귀 테스트 실행 매크로

```

□ ② 피드 보기/올리기        (2분)
□ ③ 리그 생성/참가         (2분)
□ ④ 마이리그 3개 탭        (1분 30초)
□ ⑤ 검증 기능             (1분 30초)
□ ⑥ 프로필 보기/수정       (1분)
─────────────────────────
  합계 약 9-10분
```
