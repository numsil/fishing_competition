## 팀전(Team Mode) 체크리스트

2026-11-23 추가. 팀전은 호스트가 켜는 리그 옵션이고, 꺼진 리그는 기존과 100% 동일해야 한다.

### 일반 리그 (팀전 OFF) — 회귀가 없어야 하는 쪽

- [ ] 리그 목록 → 상세 진입. 탭이 늘지 않았는지 (진행중 호스트 3개 / 그 외 2개)
- [ ] 진행중 리그의 순위 탭 하단에 **조과 사진 등록 버튼**이 보이는지
- [ ] 개인 순위에 팀 배지(색 점)가 **안 보이는지**
- [ ] 리그 관리 화면에 `팀 관리` 버튼이 **안 보이는지**
- [ ] 리그 개설 화면의 경기 방식·집계 조과 수 칩이 그대로 동작하는지

### 팀전 리그 (팀전 ON)

- [ ] 개설 시 `팀전으로 진행` 토글 → 저장 후 수정 화면에서 켜진 채로 복원되는지
- [ ] 리그 관리 → `팀 관리` → 팀 추가. 같은 이름 재추가 시 "이미 같은 이름의 팀이 있습니다."
- [ ] 팀 색 점을 탭해 색 변경이 되는지. **팀을 지우고 새로 추가했을 때 남은 팀과 색이 겹치지 않는지**
- [ ] `자동 셔플` → 참가자가 팀에 고르게 나뉘는지 (팀 0개면 버튼 비활성)
- [ ] 팀원 줄을 눌러 다른 팀/미배정으로 옮겨지는지
- [ ] 팀 삭제 → 팀원이 미배정으로 돌아가고 **조과와 참가자 수는 그대로**인지
- [ ] 상세 화면이 `팀 순위` 탭으로 열리는지. 팀 2~4개면 카드가 **처음부터 펼쳐져** 있는지
- [ ] **개인 순위 탭에서도 조과 사진 등록 버튼이 보이는지** (팀 탭을 맨 앞에 넣은 탓에 한 번 깨진 적 있음 — 1.0.3 이전 회귀)
- [ ] 팀원 줄 탭 → 참가자 상세로 이동하고 **아바타 순위 배지가 0이 아닌 실제 순위**인지
- [ ] 조과 0마리 팀원이 흐리게 보이되 인원수에는 포함되는지
- [ ] 미배정 참가자가 맨 아래 그룹에 모이고 팀 점수에 반영되지 않는지
- [ ] 팀이 0개인 팀전 리그에서 팀 탭이 예외 없이 안내 문구를 보이는지
- [ ] 개인 탭 각 줄에 색 점 + 팀명 배지가 보이는지 (미배정은 "팀 미배정")
- [ ] `마릿수` 룰 팀전 리그에서 팀 순위가 **마릿수 많은 순**인지 (길이 순이 아님)
- [ ] 호스트가 아닌 계정으로 같은 리그를 보면 팀 관리 진입 버튼이 없는지

### DB 불변식 (psql)

```sql
-- 팀전을 쓰지 않는 리그/참가자는 전부 기본값이어야 한다
SELECT count(*) FROM leagues WHERE is_team_mode;              -- 쓰는 만큼만
SELECT count(*) FROM league_participants WHERE team_id IS NOT NULL;
-- 조과 보호: posts.league_id 는 반드시 RESTRICT('r')
SELECT confdeltype FROM pg_constraint WHERE conname='posts_league_id_fkey';
-- 팀 삭제 시 멤버만 풀려야 한다: team_id 는 SET NULL('n')
SELECT confdeltype FROM pg_constraint WHERE conname='league_participants_team_id_fkey';
```

### 팀전 v2 — 팀 배정 방식 (2026-11-23)

#### 기존 기능 비회귀 (팀전을 쓰지 않는 리그)

- [ ] 일반 리그 상세: 탭 개수·순서가 이전과 같다 (팀 순위 탭 없음)
- [ ] 일반 리그 개인 순위 탭: 팀 배지가 없고 하단 조과 등록 버튼이 있다
- [ ] 일반 리그 개설 화면: 팀전 토글이 꺼져 있고 하위 설정(배정 방식·정원)이 보이지 않는다
- [ ] 일반 리그 목록 / 내 리그: 이전과 동일하게 뜬다
- [ ] 기존 리그를 수정 저장했을 때 `team_capacity` 가 0 그대로다 (정원이 생기지 않는다)

#### 팀전 — 호스트 배정 모드 (v1 동작 유지)

- [ ] 팀 순위 탭에 **내 팀 배너가 보이지 않는다** (누를 수 없는 버튼을 보여주면 안 된다)
- [ ] 팀 관리: 팀 카드가 **기본으로 접혀** 있고 한 줄에 색·이름·인원이 보인다
- [ ] 팀 카드를 탭하면 펼쳐지고 멤버 줄 + `팀원 추가` 버튼이 나온다
- [ ] 정원 0(무제한)이면 카드에 `N명` 으로 표시된다
- [ ] 멤버 줄 탭 → 팀 선택 시트 → 다른 팀으로 이동된다
- [ ] 팀이 8개 이상이면 팀 선택 시트에 검색창이 나오고 필터가 된다
- [ ] 팀 이름 변경 / 색 변경 / 삭제가 v1 과 동일하게 동작한다
- [ ] 팀 삭제 시 멤버가 미배정으로 돌아가고 조과가 유지된다

#### 팀전 — 정원

- [ ] 팀 관리 상단의 `팀당 정원` 스테퍼로 정원을 바꿀 수 있다
- [ ] 정원을 5로 두면 카드에 `3 / 5` 로 표시된다
- [ ] 정원이 찬 팀의 `팀원 추가` 버튼이 `정원이 찼습니다` 로 비활성된다
- [ ] 정원을 **현재 인원보다 작게** 줄이면 `6 / 5` 로 경고색 표시되고 멤버는 빠지지 않는다
- [ ] 그 초과 상태에서 멤버를 **빼는** 배정이 성공한다 (복구 가능해야 한다)
- [ ] **여러 팀이 동시에 초과인 상태**에서도 한 팀에서 빼는 배정이 성공한다
      (손대지 않은 초과 팀 때문에 거부되면 안 된다 — v2에서 실제로 났던 버그)
- [ ] 그 초과 상태에서 멤버를 **더 넣는** 배정이 `방금 정원이 찼습니다` 로 거부된다

#### 팀전 — 팀원 다중 추가

- [ ] 펼친 팀의 `팀원 추가 · N자리 남음` → 체크박스 시트가 뜬다
- [ ] 검색으로 이름 필터가 되고, 다른 팀 소속도 결과에 나오며 현재 소속이 표시된다
- [ ] 남은 자리를 넘는 줄이 `자리 없음` 으로 비활성된다
- [ ] `전체 선택` 이 남은 자리만큼만 고른다
- [ ] 확인 시 고른 인원이 **한 번에** 그 팀으로 들어간다
- [ ] 아무도 안 고르면 하단 버튼이 비활성이다

#### 팀전 — 셔플 되돌리기

- [ ] `자동 셔플` 성공 시 스낵바에 `되돌리기` 액션이 있다
- [ ] 스낵바가 사라진 뒤에도 요약 바에 `되돌리기` 버튼이 남는다
- [ ] `되돌리기` 를 누르면 셔플 **직전** 배정으로 정확히 복구되고 버튼이 사라진다
- [ ] 정원이 작아 전원을 못 담는 상태(참가자 > 팀 수 × 정원)에서 셔플이
      `정원이 너무 작습니다` 로 거부된다
- [ ] 되돌리기 전에 그 스냅샷의 팀을 삭제하면 **되돌리기 버튼이 바로 사라진다**
- [ ] 화면을 나갔다 다시 들어오면 `되돌리기` 버튼이 없다 (스냅샷은 화면 state)

#### 팀전 — 참가자 자율 선택

- [ ] 개설 화면에서 `참가자가 선택` 을 고르면 안내 문구가 바뀐다
- [ ] 자율 모드 리그의 팀 순위 탭 최상단에 배너가 뜬다
      (미배정이면 큰 카드, 배정됐으면 `내 팀: X팀` 한 줄 + `변경`)
- [ ] `내 팀 선택` → 팀 목록에 `3 / 5 · 2자리 남음` 과 멤버 아바타가 보인다
- [ ] 정원이 찬 팀은 흐리게 + 자물쇠 + `정원 마감` 이고 탭이 안 된다
- [ ] **현재 내 팀은 정원이 차 있어도 흐려지지 않는다** (내가 한 자리를 차지하고 있다)
- [ ] 팀을 고르면 즉시 반영되고 이전 화면으로 돌아가며 순위가 갱신된다
- [ ] `팀에서 나가기` → 미배정이 되고, 배너가 미배정 상태로 바뀐다
- [ ] 미배정이면 `팀에서 나가기` 버튼이 보이지 않는다
- [ ] 자율 모드인데 팀이 0개면 배너가 `호스트가 팀을 만들면...` 이고 버튼이 비활성이다
- [ ] 자율 모드에서도 **호스트는 팀 관리로 계속 배정·셔플할 수 있다**
- [ ] `self` → `host` 로 바꾸면 기존 배정이 유지되고 배너만 사라진다

#### DB 불변식 (psql)

```sql
-- 기존 리그는 전부 host / 0 이어야 한다 (자율로 바꾼 리그 제외)
```
